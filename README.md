# Alexandre Autran — portfolio

Static website ready for GitHub Pages or any static host.

- Open `index.html` locally or upload the folder as-is.
- PDFs are stored directly under `documents/` and all website PDF links are local.
- No external JavaScript, CSS framework, font, or build step is required.
- Default appearance is dark mode; the toggle is persistent in the browser.

## Document import

Imported 154 PDF files (byte-identical duplicates in `research.zip` were stored once).

The ten L1 exercise sheets `Feuille n°1` to `Feuille n°10` are included under `documents/resources/exercise-sheets/` and linked directly from the Resources section.

- `.nojekyll` is included so GitHub Pages serves the static files directly.
